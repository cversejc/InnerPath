### 用户测评流程
```
用户填写信息
   ↓
提交测评
   ↓
调用 DeepSeek AI
   ↓
AI 生成报告（2-5秒）
   ↓
解析并结构化
   ↓
保存到本地存储
   ↓
显示报告预览
   ↓
用户可选择：
  - 查看完整报告
  - 预约深度咨询
  - 学习系统课程
```

### AI 生成逻辑
```javascript
// 1. 构建提示词
const prompt = buildPrompt(userData)

// 2. 调用 DeepSeek API
const response = await axios.post(DEEPSEEK_API_URL, {
  model: 'deepseek-chat',
  messages: [
    { role: 'system', content: systemPrompt },
    { role: 'user', content: prompt }
  ],
  temperature: 0.7,
  max_tokens: 2000
})

// 3. 解析 AI 响应
const aiContent = response.data.choices[0].message.content

// 4. 结构化报告
const report = parseAIResponse(aiContent, userData)
```

## 🛡️ 错误处理

### 降级策略
```javascript
try {
  // 尝试调用 DeepSeek AI
  return await generateReportWithAI(userData)
} catch (error) {
  console.error('DeepSeek API 调用失败:', error)
  // 降级到基础算法
  return generateBasicReport(userData)
}
```

### 基础算法
当 AI 调用失败时，系统会自动切换到基础算法：
- 基于五行的简化分析
- 预设的能量类型模板
- 通用的成长建议

### 错误提示
- API 调用失败：提示用户稍后重试
- 网络错误：检查网络连接
- 配额不足：联系管理员

## 🐛 常见问题

### Q1: API 调用失败怎么办？
**A**: 系统会自动降级到基础算法，用户仍能获得报告。检查：
- API Key 是否正确
- 网络连接是否正常
- API 配额是否充足

### Q2: 报告生成时间过长？
**A**: 正常情况下 2-5秒。如果超过 10秒：
- 检查网络速度
- 查看浏览器控制台错误
- 尝试刷新页面重试

### Q3: 如何测试 API 是否正常？
**A**: 使用 `test-api.html` 独立测试工具：
```bash
open test-api.html
```

### Q4: CORS 错误怎么解决？
**A**: DeepSeek API 支持跨域请求。如果遇到 CORS 错误：
- 检查 API 地址是否正确
- 确认 Authorization header 格式
- 考虑通过后端代理请求
