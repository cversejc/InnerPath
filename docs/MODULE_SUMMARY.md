**功能模块**:

  - 稳定承载型（土）
  - 秩序驱动型（金）
  - 智慧流动型（水）

- ✅ **十神心理动力映射**
  - 将传统十神转化为9种心理驱动模式
  - 每种模式包含：心理模式、行为特征、关系表现、成长方向

- ✅ **完整报告生成**
  - 能量特质分析
  - 职业发展建议
  - 关系模式解读
  - 个性化行动方案
  - 成长资源推荐

**差异化优势**:
- 不是简单的"断事"，而是提供成长路径
- 结合用户选择的议题，生成针对性建议
- 可扩展的算法架构，便于后续优化

## 产品定位实现

- ❌ 不用: "算命"、"八字"、"紫微"、"预测"
- ✅ 使用: "东方能量测评"、"时间节律分析"、"能量类型"、"心理动力"

```
引流层: 免费/低价能量测评 (¥0-199)
   ↓
转化层: 系统课程学习 (¥399-999)
   ↓
利润层: 1对1深度咨询 (¥1599-3599)
```

### ✅ 差异化优势
1. **融合创新**: 东方智慧 + 现代心理学
2. **结构视角**: 从"结构"而非"问题"进入
3. **成长导向**: 授人以渔，反对宿命论
4. **本土化**: 符合东方文化心理

## 技术架构

### 前端技术栈
- Vue 3 (Composition API)
- Vue Router 4 (Hash模式)
- Vite 5 (构建工具)
- 原生CSS (响应式设计)

### 核心工具
- `reportGenerator.js`: AI报告生成引擎
  - 五行能量分析
  - 十神心理映射
  - 个性化建议生成

### 数据流
```
用户输入 → 测评模块 → 报告生成引擎 → 本地存储 → 用户中心
```

## 用户旅程设计

```
访问首页
   ↓
点击"开始探索" → 进入能量测评
   ↓
填写基本信息（出生时间）
   ↓
选择关注议题（职业/关系/成长等）
   ↓
生成个性化报告
   ↓
查看报告预览 → 三个选择:
   ├─ 预约深度咨询 → 选择套餐 → 填写预约信息 → 预约成功
   ├─ 学习系统课程 → 查看课程大纲 → 选择版本 → 报名
   └─ 查看完整报告 → 进入用户中心 → 管理报告/预约/课程
```
