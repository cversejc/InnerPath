## 更新与初始化

修改来源文档后，在仓库根目录运行：

```powershell
py -3.11 backend/tools/sync_skill_frameworks.py
py -3.11 backend/tools/sync_skill_frameworks.py --check
```

脚本只提取上述文档，生成 `backend/app/domains/skills/framework_guidance.json` 的当前内容，并记录来源章节和文档摘要。Markdown 标记与排版被转成可编辑文字，固定输出长度继续留在程序契约中。运行服务只读取随程序打包的当前内容，不依赖工作目录中的文档或工具脚本。

初始化使用当前思路和既有程序契约，直接生成已发布版本。后台人工维护过的技能仍由管理员发布的思路决定，初始化不自动覆盖；本次按用户要求补全当前库时另行发布。后续新案例、新日历使用最新发布绑定，既有案例和日历保留冻结引用。

用户明确要求用文档重新发布当前库时，可以在后端容器运行 `python -m tools.publish_skill_frameworks --publish --replace-admin-guidance`。该命令在同一事务中发布当前内容并更新新报告流程的绑定，历史记录保持原引用；平时不应把显式覆盖参数加入服务启动脚本。

管理员维护目标与思考方法。输入投影、输出字段、引用约束、固定校验、模型参数和发布流程仍由程序负责。文档同步检测与技能回归验证分别检查内容是否漏同步、分层编译与生产链路是否兼容。

## 旧整份报告技能退役

`report.generate`（人生说明书报告生成）已被七个现行报告技能替代，退出维护目录。启动和演示初始化不再创建它；启动在更新现行流程后，将已有版本标记为 `RETIRED`。原版本内容、历史流程与案例快照保留，便于核对历史引用。

新流程 S5 使用 `authoring_mode=NARRATIVE_FRAGMENTS`，通过已冻结的主线规划与逐段写作技能执行，不再绑定旧整份报告技能；流程只冻结七个现行报告技能。现行协作权限和人工完成规则保持原流程设置。

退役身份由 Skills 领域的 `lifecycle.py` 管理。后端阻止创建、修改、发布、排队和直接执行该技能，也阻止将它加入新流程的冻结绑定。旧通用 S5 节点运行接口返回 `report_authoring_workflow_required`，引导使用需要确认主线和来源的正式写作链路。已完成记录继续可读，历史绑定不会因清理而被批量重写。

`ensure_default_skill_version` 仅作为历史读取兼容入口保留：它不会创建版本，空库调用会返回 `skill_retired`。正常启动、流程初始化和演示脚本都使用现行技能初始化。
