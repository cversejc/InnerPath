# 节点方向连续审核

## 咨询师工作顺序

核对上游输入与程序计算 → 运行 AI 分析 → 选择分析方向 → 审核关联判断 → 确认分析内容 → 下一方向 → 节点总览复核。

S1–S4 使用同一连续审核组件。在 AI 分析页原位处理判断和正文；判断审核页、分析内容页保留为整个节点的复核与编辑入口。

每个方向按照 AI 结果中明确保存的引用组织判断。方向顺序采用该次运行的 SOP 主题顺序。没有被任何分析引用的候选列入“其他待审判断”，防止遗漏。

## 处理规则

- 优先审核当前判断依赖的来源判断。共用判断的审核结果同步到所有引用方向。
- 确认或拒绝判断后继续当前方向的下一条待审判断，处理完进入分析正文。
- 拒绝判断不代表确认分析。咨询师须修订正文与引用；保留的判断引用须全部确认，且至少保留一条判断或一项有效资料依据。
- 前序节点判断只读；需要更正时由来源节点复核，或修订当前分析的正文和引用。
- 确认分析后进入下一待办方向。暂缓仅切换待办，不增加完成进度。
- 修改和审核结果一起保存；保存失败保留编辑内容与位置，成功后原位刷新并推进。
- 已确认内容再次修订沿用版本冲突检查，并使受影响的下游内容重新复核。
- 完成所有候选方向仍需回节点总览检查完整性，由咨询师明确完成节点。

## 实现边界

方向与引用的整理位于报告内容前端领域。保存调用报告内容 API；HTTP 适配器把可选人工修订传入既有应用编排，由内容领域建立版本和验证引用。AI 原始运行结果保持可追溯。

来源有效性、节点权限、运行激活版本、当前内容版本与确认引用均继续由后端校验。方向完成状态来自持久化的审核记录，候选自身携带的状态不能作为已审核结果。

## 写作与最终审核的接续

S5 确认主线后直接进入编排，启动顺序生成后展示进度；本次生成和连贯检查完成且咨询师仍在等待界面时，接入逐段审稿。正文按编排排序，确认后定位下一待审段落，共用编辑器原位展示判断、分析和资料来源。全部段落确认后明确提示连贯性复核与节点完成。

S6 按阻断、重要、一般的顺序处理问题。在问题旁查看和修订涉及正文；未指明段落的问题可以选择正文核对。保存处理理由后进入下一待办。正文修改使旧检查失效时，当前问题和未提交理由仍留在界面供记录，最终交付必须重新检查当前全文。问题关闭不等同于最终人工确认或交付。

编辑和保存期间阻止误切换节点、页签及段落；保存失败保留本条输入。正文版本冲突后保留修改，并允许取消修改、载入最新版。

## 节点完成与专业归属

完成节点后打开下一待办节点总览。节点只激活为待开始；负责人明确点击“开始本节点”后进入上游输入。S1–S3 归命理咨询师，S4–S6 归心理咨询师；跨专业或未接单时明确说明交接与分配状态。

旧报告的流程版本和节点任务已冻结，仅修改新流程不能修复已有任务。迁移 018 纠正仍处于 PENDING/READY、从未开始的旧心理归属 S1–S3，并依据申请的命理负责人分配。原始流程定义、申请快照和已完成节点保持原有历史；任务配置记录旧归属，审计日志记录修正。已开始工作的节点不由迁移静默改派。
