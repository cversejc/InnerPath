# 咨询师工作台操作手册

适用对象：命理咨询师、心理咨询师。适用范围：人生说明书报告申请的受理、分析、写作、审核与交付；以下完整协作流程以“综合（命理 + 心理）”方向为例。系统也支持“命理”和“心理”方向，咨询方向会影响咨询师的接单资格。当前报告节点仍按固定专业分工运行：S1–S3 由命理专业负责，S4–S6 由心理专业负责；单方向申请的可处理范围和负责人以工作台显示为准，不要据咨询方向自行跳过节点。界面名称以当前工作台为准。更新日期：2026-10-06。

## 一、进入工作台与打开申请

1. 使用咨询师账号登录，进入“咨询工作台”（`/staff`）。
2. 在报告列表选择“待接单”或“我的报告”，再按状态筛选。待接单列表只显示必要摘要；确认由自己承接后，点击“接单并查看资料”。已分配给自己的申请可直接打开。
3. 打开申请后先看报告处理总览、申请时确认的档案和本次情境。确认出生信息、用户关注的问题及补充材料是否齐全、是否相互矛盾。
4. 进入当前待办节点，阅读“任务说明”，然后点击“开始本节点”。只有本节点负责人可以修改或运行分析；其他专业的咨询师可以查看已完成成果，但不能代替负责人审核。

综合方向报告由两个专业依次协作：S1–S3 由命理咨询师负责，S4–S6 由心理咨询师负责。管理员可分别指派两个专业负责人。节点显示“待开始”时，负责人须先开始节点；显示“等待上一步”时，应先等前序节点完成。申请分配、补问等待或节点状态不允许写入时，相关按钮会不可用。

## 二、理解证据、判断与分析

| 内容 | 是什么 | 在审核时问自己 | 对最终报告的贡献 |
| --- | --- | --- | --- |
| **证据** | 可追溯的输入或资料来源，例如用户确认的出生档案、问卷回答、本次情境、用户补答，以及系统测算或有理由的咨询师修订。证据说明“资料里有什么”，本身不等于心理结论。 | 这是用户明确提供的事实、系统计算结果，还是咨询师解释？来源和版本是否正确？有没有相反或缺失的信息？ | 为判断和分析提供事实锚点。写作时可以不逐条照抄，但重要结论应能回查依据；资料不足时应明确边界或补问，不要猜测。 |
| **判断** | 从资料中提炼出的专业主张，例如某种应对倾向、资源、卡点或行动方向。每条判断应标明相关资料依据；必要时也可关联已确认的其他判断。判断是专业解释，不是用户原话或诊断。 | 结论是否超出证据？反证是否改变结论？把握程度和报告呈现程度是否合适？ | 作为报告的“结论素材”和内容取舍依据。只有咨询师确认的判断才进入后续节点和写作主线；拒绝的判断不会自动改写关联分析，须同时修订正文和引用。 |
| **分析** | 围绕一个主题对证据和判断作进一步解释，说明线索之间的关系、可能的作用、现实影响、矛盾与不确定性。它是结构化的专业推理内容，还不是面向客户的最终叙述。 | 推理链是否完整？是否区分事实与假设？是否使用已确认判断或有效资料？主题是否覆盖，缺资料是否有暂缓理由和待补问题？ | 把零散判断连成对个案有用的理解，为S3整合、S4卡点与行动，以及S5报告主线和段落提供内容。确认后的分析会被写作引用或改写；不会因为AI生成就自动成为报告结论。 |

判断还带有语义角色、把握程度、参考优先级和报告呈现程度。呈现程度可选“仅供内部参考”“可酌情呈现”“建议呈现”“报告需要包含”：它帮助S5决定段落取舍与重点，不代表把判断原文直接贴进报告；即使标为“需要包含”，仍须核对正文是否准确、合适并通过最终审核。语义角色则帮助后续节点区分资源、卡点和行动等用途，例如成长实验应回应已确认的卡点。

可以用这条链理解三者关系：

```text
用户资料 / 程序测算
        ↓ 核实来源、准确度与版本
证据 → 有依据的专业判断 → 主题分析与整合 → 报告主线和段落 → 最终复核与交付
```

**示例：**用户说“临时请求来了我常常马上答应，之后熬夜完成”。这句话是用户自述证据；“在余量不清楚时，可能先回应他人、后评估自己的负荷”可以成为待核实判断；分析可进一步讨论这种做法短期如何帮助维持合作、长期可能付出什么代价，并说明适用情境和反例。只有核对原话、关联资料、把握程度和解释边界后，咨询师确认的内容才可被S5用于报告。不可把这段推理扩写成用户未说过的童年经历或固定人格标签。

## 三、S1–S4：核实资料并完成分析

S1–S4 的节点内界面通常依次包含“上游输入”“AI 分析”“判断审核”“分析内容”；S1 另有“程序计算”。可以先查看“任务说明”与“上游输入”，再按界面导航处理。AI输出均是待审候选。

### S1 命理基础

1. 在“上游输入”核对本次确认的出生日期、时间、地点、历法和用户问题。
2. 进入“程序计算”。如尚无测算结果，点击“运行程序测算”；对照出生资料检查四柱、大运、紫微结构等结果。
3. 只有确认存在排盘或资料错误时才点“修订程序测算”，在对应字段修订并写明原因，再保存。修订会形成新依据版本；引用旧版本的判断或内容可能需要重新审核。
4. 进入“AI 分析”运行建议。逐方向审核关联判断，再确认分析内容；在“判断审核”“分析内容”页也可以复核、编辑本节点全部相关条目。
5. 命盘提供命理结构线索，不足以证明心理事实、经历或未来结果。格局、旺衰、用神等解释须结合资料审核；不确定的心理含义留给后续核验。

### S2 心理映射

1. 先读用户对现实处境、感受和做法的自述，再查看S1已确认内容及其资料来源。
2. 对每条候选判断区分“用户说过/做过什么”和“咨询师对其意义的解释”。S1命理判断只作辅助线索，不能单独充当心理证据。
3. 核对支持材料、反证、适用情境和不确定性；没有足够现实资料时，不把假设写成事实，可暂缓并提出具体补问。

### S3 三重整合

1. 只使用S1、S2已经确认的判断和分析。
2. 对照哪些内容互相支持、彼此冲突或仍缺信息，确认是否有资料来源。
3. 提炼与用户现实议题相关的核心张力和发展方向，不把解释写成绝对标签或确定的未来预测。

### S4 机制、卡点与行动

1. 从用户正在面对的具体情境出发，核对触发点、想法、感受和应对方式。
2. 说明应对方式短期保护了什么、长期可能付出什么代价；不要把“卡点理解”和“行动建议”混成一条未经说明的结论。
3. 审核成长实验是否对应已确认卡点，且写清具体动作、频率、耗时、观察方式和停止/调整条件。系统要求确认3–5项可执行成长实验；行动应低成本、可逆，不替用户作重大决定。

### S1–S4 的连续审核操作

1. 在“AI 分析”中选择本次运行记录。分析运行摘要和风险提示用于定位核对重点，不替代逐项审核。
2. 按方向先审关联判断：查看完整判断、语义角色、把握程度和资料依据。选择“修改判断”后，调整内容、资料引用、把握程度及呈现程度；然后“确认判断并继续”。确实不成立时用“拒绝判断并继续”。
3. 共享判断只需审核一次。若拒绝或修改判断，要回到关联分析，修订分析正文并同步调整引用；被拒绝的判断不会令旧分析自动通过。
4. 审核该方向的分析内容，检查正文、引用判断、资料来源及“覆盖说明与推导记录”。确认正文有依据且准确后，点“确认分析并进入下一方向”。修改后尚未准备确认时，可保存为待确认。
5. 资料不足时，可在分析的覆盖说明中选择“资料不足，暂缓并补问”，写清暂缓理由、当前正文中的依据摘句和待补问题。需要用户回答时，在节点总览使用“向用户补问”；申请会等待用户回复，回复作为新增资料进入原节点，咨询师收到后继续核对。AI分析运行中不能同时补问。
6. 暂缓方向只会切换待办，不会增加完成进度。处理完所有候选后回节点总览，查看系统提示的阻断项，再点击“确认成果并进入下一节点”。

## 四、S5：选择报告主线并逐段写作

1. 进入“AI 写作与编排”中的“主线方案”，点击“生成报告主线建议”。主线是内容组织建议，不会改变已确认的专业判断。
2. 对照用户本次问题查看候选主题、主要依据和暂不展开的判断。可修订核心主题、重点回应的判断或强调方向，然后点击“选择并确认这条主线”。
3. 进入“逐段编排”，检查段落顺序、章节、写作目的、主要判断、相关分析和行动来源。若出现缺少依据或内容缺口，先回到来源判断/分析处理；不要要求写作环节补造结论。
4. 点击“按顺序生成报告内容”，等待各段及章节/全文连贯检查完成。若内容生成中断，可使用“继续生成未完成内容”；检查未通过或失效时，按界面提示修订来源或重新检查。
5. 进入“逐段审稿”，每段先展开“核对本段依据”，检查引用的判断、分析和资料是否确实支持正文。可修改标题和正文；区分“只调整表达方式”与“调整内容含义”。确认后点击“确认本段并继续下一段”。
6. 改动正文含义时，核对引用和受影响段落；发现新增专业结论或依据不足，应退回相应上游节点处理。全部段落确认、连贯性检查完成后，再回节点总览完成S5。

## 五、S6：质量审核与交付

1. 进入“AI 检查与问题”，首次点击“运行交付前检查”。检查报告正文、来源和质量问题；AI评分与意见只是复核线索，人工仍需逐条判断。
2. 在“待处理问题”中优先处理“阻断”，再处理重要和一般问题。点击“查看并修订涉及正文”可在问题旁打开段落及其来源。
3. 修订内容后，为该问题填写处理方式和理由并保存。阻断问题必须修复；其他问题可以在确有依据时保留或标记为误报，但必须写明核对依据。关闭问题不等于通过最终复核。
4. 任何正文修改都会使原检查结果失效。点击“重新检查完整报告”，确认当前版本的检查完成、阻断项清零，并通读全文、主线及所有处理记录。评分门槛为总分至少80、事实忠实度至少16、不确定性与安全至少8；达标仍须咨询师人工确认。
5. 勾选“我已复核报告主线、用户贴合度和全部检查记录，并承担最终交付责任”，点击“确认最终复核”。之后点击“生成并交付版本”并再次确认。
6. 交付后，工作台“交付成果”卡片可打开客户实际收到的最终报告，并返回申请查看分析过程。交付版本不可覆盖；交付前草稿不会向用户开放。

## 六、审核时的几个关键原则

- **AI候选不等于证据或结论。**AI分析、主线、正文和质量检查都需要咨询师依据来源核实。
- **判断与分析必须能回到来源。**对重要判断保留资料引用；对引用的矛盾、错误和失效版本及时修订。资料来源更新后，旧成果显示需要复核时，应先处理上游依据。
- **不确定性要被看见。**用户未提供、资料冲突或推理不足时，选择暂缓、补问或缩小结论范围，不自行填补空白。
- **写作不新增专业结论。**S5负责组织和表达已确认内容；改变实质含义时回到对应判断或分析审核。
- **完成按钮有业务门槛。**待审核判断、分析覆盖、写作段落或最终质量事项未完成时，系统会说明尚需处理的内容；不要绕过门槛直接交付。
- **记录修改理由。**测算修订、质量问题保留/误报及关键内容修订都应留下可理解的理由，方便后续追溯。
