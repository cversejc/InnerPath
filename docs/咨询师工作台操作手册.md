# 咨询师工作台操作手册

适用对象：命理咨询师、心理咨询师。适用范围：人生说明书报告申请的受理、分析、写作、审核与交付；以下完整协作流程以“综合（命理 + 心理）”方向为例。系统也支持“命理”和“心理”方向，咨询方向会影响咨询师的接单资格。当前报告节点仍按固定专业分工运行：S1–S3 由命理专业负责，S4–S6 由心理专业负责；单方向申请的可处理范围和负责人以工作台显示为准，不要据咨询方向自行跳过节点。界面名称以当前工作台为准。更新日期：2026-10-07。

## 一、进入工作台与打开申请

1. 使用咨询师账号登录，进入“咨询工作台”（`/staff`）。
2. 在报告列表选择“待接单”或“我的报告”，再按状态筛选。待接单列表只显示必要摘要；确认由自己承接后，点击“接单并查看资料”。已分配给自己的申请可直接打开。
3. 打开申请后先看报告处理总览、申请时确认的档案和本次情境。确认出生信息、用户关注的问题及补充材料是否齐全、是否相互矛盾。
4. 进入当前待办节点，阅读“任务说明”，然后点击“开始本节点”。只有本节点负责人可以修改或运行分析；其他专业的咨询师可以查看已完成成果，但不能代替负责人审核。

综合方向报告由两个专业依次协作：S1–S3 由命理咨询师负责，S4–S6 由心理咨询师负责。管理员可分别指派两个专业负责人。节点显示“待开始”时，负责人须先开始节点；显示“等待上一步”时，应先等前序节点完成。申请分配、补问等待或节点状态不允许写入时，相关按钮会不可用。

## 二、理解证据、判断与分析

| 内容 | 是什么 | 在审核时问自己 | 对最终报告的贡献 |
| --- | --- | --- | --- |
| **证据** | 可追溯的输入或资料来源，例如用户确认的出生档案、问卷回答、本次情境、用户补答，以及系统测算或有理由的咨询师修订。证据说明“资料里有什么”，本身不等于心理结论。 | 这是用户明确提供的事实、系统计算结果，还是咨询师解释？来源和版本是否正确？有没有相反或缺失的信息？ | 为判断和分析提供事实锚点。写作时可以不逐条照抄，但重要结论应能回查依据；资料不足时应明确边界或补问，不要猜测。 |
| **判断** | 从资料中提炼出的专业主张，例如某种应对倾向、资源、卡点或行动方向。每条判断应标明相关资料依据；必要时也可关联已确认的其他判断。判断是专业解释，不是用户原话或诊断。 | 结论是否超出证据？反证是否改变结论？把握程度和报告呈现程度是否合适？ | 作为报告的“结论素材”和内容取舍依据。只有咨询师确认的判断才进入后续节点和写作主线；拒绝的判断不会自动改写关联分析，须同时修订正文和引用。 |
| **分析** | 围绕一个主题对证据和判断作进一步解释，说明线索之间的关系、可能的作用、现实影响、矛盾与不确定性。它是结构化的专业推理内容，还不是面向客户的最终叙述。 | 推理链是否完整？是否区分事实与假设？是否使用已确认判断或有效资料？主题是否覆盖，缺资料是否有暂缓理由和待补问题？ | 把零散判断连成对个案有用的理解，为S3整合、S4卡点与行动，以及S5报告主线和段落提供内容。确认后的分析会被写作引用或改写；不会因为AI生成就自动成为报告结论。 |

判断还带有语义角色、把握程度、参考优先级和报告呈现程度。呈现程度可选“仅供内部参考”“可酌情呈现”“建议呈现”“报告需要包含”：它帮助S5决定段落取舍与重点，不代表把判断原文直接贴进报告；即使标为“需要包含”，仍须核对正文是否准确、合适并通过最终审核。语义角色则帮助后续节点区分资源、卡点和行动等用途，例如成长实验应回应已确认的卡点。

可以用这条链理解三者关系：

```text
用户资料 / 程序测算
        ↓ 核实来源、准确度与版本
证据 → 有依据的专业判断 → 主题分析与整合 → 报告主线和段落 → 最终复核与交付
```

**示例：**用户说“临时请求来了我常常马上答应，之后熬夜完成”。这句话是用户自述证据；“在余量不清楚时，可能先回应他人、后评估自己的负荷”可以成为待核实判断；分析可进一步讨论这种做法短期如何帮助维持合作、长期可能付出什么代价，并说明适用情境和反例。只有核对原话、关联资料、把握程度和解释边界后，咨询师确认的内容才可被S5用于报告。不可把这段推理扩写成用户未说过的童年经历或固定人格标签。

## 三、S1–S4：核实资料并整体审核

S1–S4 保留“上游输入”“AI 分析”“判断审核”“分析内容”“节点复核”等分步界面；S1 另外保留“出生资料与时间核对”和“程序计算”。AI输出先作为待审候选加入本节点。判断和分析分别整体确认；只有发现具体问题时才单独修改、拒绝或暂缓条目。

### S1–S4 通用操作

1. 查看“上游输入”，核实用户资料、现实情境、已确认的前序成果及来源。
2. 运行 AI 分析并查看本次候选、风险提示和来源。确认候选使用的依据仍有效后，一次加入本节点待审内容；加入不等于确认。
3. 进入“判断审核”通读本节点判断、来源、把握程度和呈现范围。没有争议时一次整体确认；对确有问题的条目按具体问题修改、拒绝或暂缓。
4. 进入“分析内容”通读完整分析、来源、覆盖说明和推导记录。没有问题时一次整体确认；需要修改时定位相关内容处理，其他内容不要求逐条点击通过。确认后会进入下一审核页。
5. 进入“节点复核”后，系统在所需阶段确认齐全时自动检查当前节点；处理仍未关闭的阻断或重要问题，再签核进入下一节点。顶端节点导航仍可返回已完成的工作页。

### S1 命理基础

1. 在“出生资料与时间核对”并列查看申请时留存的用户档案、原始出生时间、程序换算、采用口径、地点来源和限制。资料完整且结果无争议时一次确认；缺失、地点或来源冲突、口径不明或结果异常时，针对该问题补问或修订并说明依据。
2. 在“程序计算”查看完整四柱、十神、干支关系、大运和紫微结构等结果与依据。常规结果由程序校验，无需逐字段确认；只有发现测算错误时才修订并说明原因。修订会形成新版本，引用旧版本的内容会要求复核。
3. 集中核对时柱（或确认未知时辰的限制）、格局与喜忌，并整体审阅有来源支持的基础判断。命盘线索不能直接证明心理事实、经历或未来结果；不确定的心理含义应留待后续核验。
4. 依照 S1–S4 通用操作，分别整体确认判断和完整分析，再进入节点复核。

### S2 心理映射

1. 先读用户对现实处境、感受和做法的自述，再查看 S1 已确认内容及资料来源。
2. 整体阅读全部心理映射，区分“用户说过/做过什么”和“咨询师对其意义的解释”。S1 命理判断只作辅助线索，不能单独充当心理证据。
3. 核对支持材料、反证、适用情境和不确定性后一次整体确认。没有足够现实资料时，不把假设写成事实；只对具体争议条目修订、暂缓或补问。

### S3 三重整合

1. 只使用S1、S2已经确认的判断和分析。
2. 整体核对哪些内容互相支持、彼此冲突或仍缺信息，并检查来源。
3. 提炼与用户现实议题相关的核心张力和发展方向，整体确认本节点成果；不把解释写成绝对标签或确定的未来预测。

### S4 机制、卡点与行动

1. 从用户正在面对的具体情境出发，核对触发点、想法、感受和应对方式。
2. 说明应对方式短期保护了什么、长期可能付出什么代价；不要把“卡点理解”和“行动建议”混成一条未经说明的结论。
3. 集中核对机制与卡点的关系，以及成长实验是否回应已确认卡点；系统要求保留 3–5 项实验，并写清动作、频率、耗时、观察方式和停止/调整条件。适用时整体确认本节点成果；行动应低成本、可逆，不替用户作重大决定。

### S1–S4 的问题处理与补问

- AI 运行摘要和风险提示用于定位核对重点；判断和分析仍须分别通读完整内容、来源与覆盖信息，再各自整体确认。
- 发现错误、争议、反证或依据不足时，只对相关条目修改、拒绝或暂缓，并检查它依赖的分析和引用；保存后按提示重核受影响阶段。
- 资料不足且需要用户回答时，在节点复核中使用“向用户补问”。申请会等待回复；回复作为新增资料回到原节点，相关确认可能因版本变化失效。AI 分析运行中不能同时补问。
- 所需阶段确认完成后，在“节点复核”处理系统列出的阻断或重要问题并签核，之后才进入下一节点。

## 四、S5：确认主线并整体审阅报告

1. 进入“AI 写作与编排”中的“主线方案”，点击“生成报告主线建议”。主线是内容组织建议，不会改变已确认的专业判断。
2. 对照用户本次问题查看候选主题、主要依据和暂不展开的判断。可修订核心主题、重点回应的判断或强调方向，然后点击“选择并确认这条主线”。
3. 进入“逐段编排”，检查段落顺序、章节、写作目的、主要判断、相关分析和行动来源。若出现缺少依据或内容缺口，先回到来源判断/分析处理；不要要求写作环节补造结论。
4. 点击“按顺序生成报告内容”，查看生成进度并等待各段及章节/全文连贯检查完成。若内容生成中断，可继续生成未完成内容；检查未通过或失效时，按界面提示修订来源或重新检查。
5. 进入“完整报告审阅”，通读报告正文，并按需展开各段判断、分析和资料来源。只有实际问题需要逐段修订；普通段落不要求逐段确认。正文修订会使全文连贯性检查失效，需回到“AI 写作与编排”重检当前全文，再到节点复核一次整体确认 S5 报告内容；确认后会进入节点复核。
6. 改动正文含义时，核对引用和受影响内容；发现新增专业结论或依据不足，应退回相应上游节点处理。完成报告整体确认后，进入 S5 节点复核。

## 五、S6：质量审核与交付

1. 进入 S6 后系统会检查当前完整报告；在“AI 检查与问题”查看程序检查、七维评分和问题定位。AI 评分与意见是复核线索，咨询师仍需核对报告正文和来源。
2. 优先处理阻断和重要问题。按需从问题定位到正文及其来源；阻断问题必须修复。表达建议等普通问题可略过，保留或标记误报时按界面要求写明理由。关闭问题不等于通过最终复核。
3. 正文有改动或质量检查失效时，重新检查当前完整报告。质量门槛为总分至少 80、事实忠实度至少 16、不确定性与安全至少 8。
4. 进入“复核正文”通读当前报告、主线和处理记录，确认完整报告审阅阶段。确认后进入节点复核；正文发生变化时，受影响的确认和检查需按版本重新完成。
5. 进入“节点复核”确认所有必需阶段仍对当前版本有效、质量检查为当前版本且没有未处理的阻断或重要问题，然后点击“确认终审并交付”。签核会记录当前质量运行、报告版本、操作者和时间。
6. 交付后，工作台“交付成果”卡片可打开客户实际收到的最终报告，并返回申请查看分析过程。交付版本不可覆盖；交付前草稿不会向用户开放。

## 六、审核时的几个关键原则

- **AI候选不等于证据或结论。**AI分析、主线、正文和质量检查都需要咨询师依据来源核实。
- **判断与分析必须能回到来源。**对重要判断保留资料引用；对引用的矛盾、错误和失效版本及时修订。资料来源更新后，旧成果显示需要复核时，应先处理上游依据。
- **不确定性要被看见。**用户未提供、资料冲突或推理不足时，选择暂缓、补问或缩小结论范围，不自行填补空白。
- **写作不新增专业结论。**S5负责组织和表达已确认内容；改变实质含义时回到对应判断或分析审核。
- **完成按钮有业务门槛。**阶段整体确认、分析覆盖、报告完整审阅或最终质量事项未完成时，系统会说明尚需处理的内容；不要绕过门槛直接交付。
- **记录修改理由。**测算修订、质量问题保留/误报及关键内容修订都应留下可理解的理由，方便后续追溯。
